# Experimental history

This directory preserves earlier attempts for auditability. It is **not the submission demo**.

- `isaac-results/`: Spot integration captures, including failed tracking and stationary/policy-only movies. These do not demonstrate autonomous Spot navigation.
- `synthetic-demo/` and `synthetic-results/`: idealised 2-D planning experiments using exact pose and idealised range observations, not camera autonomy.
- `docs/`: dated handoff notes. Paths in these historical notes refer to the former repository layout.

The active simulator lives in `../webots/`. The source of the experimental Isaac adapter remains in `../isaac/` for reference.
