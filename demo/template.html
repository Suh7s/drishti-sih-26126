Experiment details and evidence boundary

Both controllers use the same obstacle inflation, A* implementation and stop supervisor. The risk-aware version also penalizes scripted terrain risk and reduces speed when the quality input falls. The source package includes a separate classical stereo and visual odometry pipeline and an experimental Isaac Sim/Spot adapter. The adapter requires validation on the Ubuntu RTX computer. Learned terrain semantics, calibrated uncertainty, loop-closing SLAM and active viewpoint recovery remain future work.
