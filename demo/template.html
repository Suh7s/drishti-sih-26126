03 / Onboard Perception & Control

Pure Computer Vision Pipeline

Zero simulator ground-truth, depth, or GPS enters the rover controller. The entire autonomy stack operates solely on paired RGB video streams.

01 / SENSE

Stereo RGB

Synchronized dual 640×400 optical sensors at 16 cm baseline with calibrated focal geometry.

02 / DEPTH

Metric 3D

Semi-Global Block Matching (SGBM) disparity, subpixel refinement, and left-right consistency filtering.

03 / LOCALISE

Visual SLAM

ORB keyframe graph, Lucas-Kanade feature tracking, and PnP-RANSAC motion estimation.

04 / PERCEIVE

Perception AI

40-feature multimodal classifier segmenting Traversable, Obstacle, Water/Mud, and Vegetation.

05 / NAVIGATE

Slope-Aware A*

RANSAC ground plane fitting, dynamic obstacle decay, and risk-weighted path planning.

Problem Statement 26126 Fulfillment

  • Path Detection: Real-time semantic discrimination of safe alluvial path vs hazards (boulders, swept timber, concrete ruins, and murky mud puddles).
  • Visual Localization: GPS-denied visual odometry achieving 2.65 cm RMSE over 9.67 m path with 99.7% continuous tracking.
  • Autonomous Navigation: Slope-aware RANSAC ground mapping and A* trajectory generation negotiating 7.5° slopes to reach the relief beacon in 36.86s.

Experimental Boundary & Integrity

  • Sensor Honesty: The rover controller only receives stereo RGB camera streams. Simulator supervisor logs truth strictly for post-run evaluation.
  • Hardware Portability: Self-contained pure NumPy + OpenCV runtime (<80ms frame compute), ready for embedded Jetson / Raspberry Pi 5 deployment without GPU dependencies.
  • Preserved Evidence: Raw frame logs, evaluation metrics, and synchronized multi-panel recordings archived for peer verification.
